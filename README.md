# EL CARTEL DE YONG

A responsive, static Spanish-language landing page for EL CARTEL DE YONG.

## Run locally

Open `index.html` in a browser. There is no build step or dependency installation required.

## Deploy

This is a static site. Configure your hosting provider to publish the repository root (`/`) with no build command. The entry point is `index.html`.

The page uses Google Fonts when a network connection is available and falls back to system sans-serif fonts otherwise.
